# BookBub Deals hide/show + daily 6PM Deal updater

Task: Lets modify the Webapp
1. In the BookBub deals list, lets add a Checkbox before the title to Hide the book.
2. Lets add a checkbox at the top of the Bookbub deals page, ""Show Hidden" to show hidden titles
3. Lets add a daily scheduled updater that will open the bookbub list for the day and update deals.db
4. The schedule updated will note in deals.db if the book is owned by me and if the deal is still current
5. These new deals will flow to the Bookbub Deals tab automatically
6. The updater will verify that the prior saved deals are still current, Expired deals are never checked again
7. Schedule the update to run at 6PM every day
8. Commit, push and deploy
